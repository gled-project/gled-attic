# Gled history

The history of Gled is in Subversion, at `https://svn.gled.org/gled`,
converted from CVS by cvs2svn in May 2003 and kept until revision 3045 in
October 2026. The GitHub repositories start from revision 3045 without
history. This directory keeps what the history said in words:

- `ChangeLogs/`: every ChangeLog of the svn trunk at revision 3045, under
  its svn path: one per libset (`libsets/<LibSet>/`), per demo directory
  (`demos/<LibSet>/`, `demos-big/AliEnViz/`), and for `gled-build/`,
  `gled-builder/` and `docs/`. GNU format, newest entry first, 2003 to
  2026.
- `actc-brad-grantham-2005-06-14.txt`: Brad Grantham's reply to the
  notification that Gled includes ACTC, which the ACTC license asks for.
  ACTC is in `libsets/Geom1/ACTC` of the gled repository.

The commit history itself is in
[osschar/gled-all](https://github.com/osschar/gled-all), an import of the
svn trunk up to revision 2975 (2015), and in full in the svn repository.
